# Лабораторная работа: проверка и поиск времени в формате ЧЧ:ММ:СС

Программа на **Python 3.10+** проверяет запись времени в 24-часовом формате (`00:00:00`–`23:59:59`) и ищет такие значения в введённом тексте, локальных файлах и на веб-страницах.

## Возможности

- Проверка, является ли **вся строка** корректным временем `ЧЧ:ММ:СС`.
- Поиск **всех совпадений** внутри произвольного текста.
- Чтение текстовых файлов (`.txt`) и HTML-файлов (`.html`, `.htm`) в UTF-8, включая UTF-8 с BOM.
- Получение страниц по HTTP или HTTPS и извлечение текста из HTML без содержимого служебных тегов (`script`, `style`, `head` и других).
- Удобное консольное меню: подсказки, повторный поиск, сообщения об ошибках и выход.
- Автоматические unit-тесты с использованием стандартного модуля `unittest`.

## Запуск в PyCharm

1. Откройте **PyCharm → Open** и выберите папку проекта, содержащую оба файла `.py`.
2. Убедитесь, что настроен интерпретатор **Python 3.10 или новее**: **Settings → Project → Python Interpreter**. Можно использовать окружение `.venv`.
3. Откройте вкладку **Terminal** внизу окна.
4. Выполните:

   ```powershell
   python time_finder.py
   ```

После запуска появится меню:

```text
ПОИСК И ПРОВЕРКА ВРЕМЕНИ — ЧЧ:ММ:СС
====================================================
1. Проверить введённое время или найти время в тексте
2. Найти время в файле (TXT, HTML)
3. Найти время на веб-странице (URL)
0. Выход
----------------------------------------------------
Выберите пункт [0–3]:
```

### Пункт 1 — ввод текста

Введите `1`, а затем, например:

```text
Начало в 09:15:00, конец в 18:45:30
```

Программа сообщит, что вся строка не является *одним* значением времени, но найдёт внутри неё два корректных значения. Если ввести только `14:30:05`, проверка всей строки будет успешной.

### Пункт 2 — поиск в файле

Создайте рядом с программой файл `schedule.txt` с содержимым:

```text
Занятие в 08:30:00; обед в 13:10:05.
```

Выберите `2` и укажите путь `schedule.txt`. Если файл расположен в другой папке, введите его полный путь. В HTML-файлах поиск ведётся по извлечённому тексту страницы.

### Пункт 3 — поиск на веб-странице

Выберите `3` и укажите полный адрес, начинающийся с `https://` или `http://`, например:

```text
https://example.org/
```

Это пример правильной записи URL, а не гарантия наличия времени на странице. Нужен доступ к интернету. JavaScript на странице программа не выполняет.

### Пункт 0 — выход

После поиска меню появляется снова. Чтобы завершить программу, выберите `0`. При ошибочном выборе или пустом вводе программа предложит продолжить работу.

## Запуск без меню

Можно сразу передать источник через командную строку (выполняется один поиск):

```powershell
python time_finder.py --text "Встреча в 12:30:45"
python time_finder.py --file schedule.txt
python time_finder.py --url https://example.org/
```

## Регулярное выражение

Для проверки **всей строки** используется шаблон:

```regex
(?:[01][0-9]|2[0-3]):[0-5][0-9]:[0-5][0-9]
```

- `(?:[01][0-9]|2[0-3])` — часы от `00` до `23`.
- `[0-5][0-9]` — минуты от `00` до `59`.
- Следующая такая же часть — секунды от `00` до `59`.
- Символы `:` между группами обязательны.

Для поиска внутри текста используется выражение с проверкой соседних символов:

```regex
(?<![\w:])(?:[01][0-9]|2[0-3]):[0-5][0-9]:[0-5][0-9](?![\w:]|\.[0-9])
```

Оно помогает не выделять время из середины слова, цепочки с дополнительным двоеточием или записи с дробными секундами.

| Ввод | Результат проверки всей строки |
| --- | --- |
| `00:00:00` | Корректно |
| `23:59:59` | Корректно |
| `12:30:45` | Корректно |
| `24:00:00` | Некорректно: часы выходят за диапазон |
| `12:60:00` | Некорректно: минуты выходят за диапазон |
| `09:30:61` | Некорректно: секунды выходят за диапазон |
| `9:30:00` | Некорректно: часы должны содержать две цифры |

## Unit-тесты

В `test_time_finder.py` предусмотрено **42 теста**. Они проверяют корректное и ошибочное время, поиск в тексте, чтение файлов, обработку HTML, загрузку страниц, ошибки и пользовательский интерфейс.

Для запуска в терминале PyCharm:

```powershell
python -m unittest -v
```

Если все тесты прошли, в конце вывода будут строки вида:

```text
Ran 42 tests

OK
```

Если появляется `FAILED`, нужно просмотреть название упавшего теста и сообщение об ошибке. Например, проверка ожидаемого текста при Ctrl+C должна совпадать с фактическим сообщением текущей версии программы.

## Покрытие кода тестами

Пакет `coverage` устанавливается отдельно:

```powershell
python -m pip install coverage
python -m coverage run --branch --source=time_finder -m unittest -q
python -m coverage report -m
```

На согласованной версии программы и тестов ранее было получено **100% покрытия строк и ветвей**. После любых изменений покрытия и тесты следует запускать повторно. Даже 100% покрытия не гарантирует отсутствия всех ошибок.

## Ограничения

- Поддерживается время без даты, часового пояса и миллисекунд; значение `24:00:00` не допускается.
- Используются обычные цифры `0–9`, по две на часы, минуты и секунды.
- PDF, Word и Excel не поддерживаются как источники поиска.
- HTML обрабатывается без выполнения JavaScript и без полноценного расчёта видимости элементов по CSS.
- Размер ответа веб-страницы ограничен приблизительно 5 МБ; сетевые операции используют тайм-аут 10 секунд.
